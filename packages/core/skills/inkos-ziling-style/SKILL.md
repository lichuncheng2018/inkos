# 紫灵风雪流修仙文风

本 Skill 是中文玄幻、修仙、仙侠、修真、高武作品的默认文风，依据紫灵风雪《每年加一点，从山野村夫成仙界道祖》前 100 章约 19 万字正文归纳。

- 用于正文写作、续写、修订、润色和文风审查。规划和设定只取其中和排事件有关的部分（招牌手法、节奏与章法），不把本 Skill 的写法写成章纲里的措辞要求或次数配额。状态结算不受本 Skill 影响，事实照常用平实的话记。
- 优先级：用户当次的明确要求 > 作品 `story/style_guide.md` 和作者意图里的文风约定 > 本 Skill > inkos-long-writing、inkos-short-writing 中的通用中文表达默认。本 Skill 放宽了通用默认里的几条（夸张的表情动作、叹号、送别处的短感慨、叙述里直接插吐槽），放宽到什么程度以下文为准；没写到的地方照通用默认执行。章长以作品设置为准。
- 作品设定明确拒绝网络梗，或要求正统、凝练的叙述口吻时，去掉梗和现代口语，叙述改用本土的俗话、成语和老话；笑点照样要有，全部来自处境反差、搭档斗嘴和旁人误会。只是世界里不许出现现代物件，或主角不是穿越者，不算禁梗：梗留在叙述者的吐槽里，人物台词用本土说法。
- 只学写法。不得搬用原作的人名（例如主角「陈浔」、灵兽「大黑牛」）、地名、宗门名、招牌道具（开山斧、悍匪头套、锅碗瓢盆之类）、金手指设定组合、情节顺序、原句和原作的梗；也不模仿原作的错别字、粗口密度和前后不一致。
- 这套文风好读，靠具体事件带出情绪起伏：日常可以热闹好笑，修行和斗法可以有期待、受挫、紧张与释然，关系变化和离别也可以留下余味。情绪跟着作品走，不套固定的“先笑后叹”章法。用词口语，四字词和成语多，句子短而有劲。

## 招牌手法

这几样最能让读者认出这套文风。用哪样看这一章的事，不凑数：规划时挑贴得上本章事件的一两样，排成具体的场次或节拍；写正文时把章纲排了的写足，章纲没排的，碰上合适的处境再顺手用。

1. 一本正经地胡闹。主角郑重其事地放一句大话、摆一个架势、下一个决心，下一段立刻落空、出糗或被搭档拆台；豪言和落差各占一段，中间常夹一个单独成段的拟声词。也用庄重的成语、古话去写鸡毛蒜皮的小事。笑点要从这一刻的处境里长出来，不靠堆梗和粗口。
2. 搭档斗嘴。主角身边有固定搭档（灵宠、师兄弟、器灵、家人）时，搭档要有自己的小心思：抢吃的、偷学、不服气、护着主角、被吓到。不会说话的搭档只出叫声，靠符号分语气（！、~、？、！！），下一段由叙述替它把意思翻出来。搭档没有台词也要有反应，不是摆设。作品里没有搭档，就把这份斗嘴落在主角的嘀咕和旁人的反应上，不为文风改设定。
3. 苟到夸张。主角的谨慎写成具体又好笑的举动：换下显眼的衣服、伪装、一动不动蹲守一整天、听见风声就搬家、打完立刻收拾干净走人。谨慎的道理讲一两句就够；主角有自己的几句处世老话，要紧时说出口。
4. 时间一笔跨过，再回头看人。一句话跨过几个月到几十年，紧跟着交代这段时间里变了什么：金手指的收益投到了哪里、在哪落脚、干什么营生、身边谁老了谁走了。送别写得克制：一两句景，主角一个小动作或一句低声的话，至多一句单独成段的短感慨，然后回到日子里。
5. 旁人眼里的主角。主角离场后切到旁人那边写一小段：宗门弟子、路人、对手怎么传、怎么误会、怎么脑补，把他当怪人、高人或野人；读者始终比旁人多知道一些。传闻可以越传越离谱。

## 节奏与章法

- 一章围绕一两件事：学一门手艺、换一个落脚处、赶一次集、送一次葬、进一次秘境、一次金手指收益后的试验。事可以小，日子只是载体，读者等的是这一章的进展：每章至少有一个看得见的变化，收益去向、境界、住处、营生、关系或旁人对主角的看法。规划时把这件事拆成当场发生的步骤，不停在「苟住」「体现长生」这种功能标签上。
- 一章的情绪随事件变化：热闹之外也可以有期待、戒备、挫败、亲近或释然；重要转折后留出人物反应和关系余波。情绪强度服从作品基调，不按固定的“笑—叹”模板排场次，也不为增加起伏硬造冲突。
- 时间推进比一般修仙文快，一章可以跨几个月到几十年；跨过去的时间必须交代变化，不能白跳。作品对时间进度另有约定时，以作品为准。
- 主角离场后可以切到旁人那边写一小段误会和议论。
- 章末大多停在叙述上：一个画面（身影走远、灯火、风）、一句平静的感慨或一个轻微的悬念；少数停在一句对白上；不停在系统提示上，也不用「他的修仙之路才刚刚开始」这类套话。
- 章名多是两段式，中间空一格：前半点出这一章的事，后半是一句俏皮话、台词、化用的老话或诗句，例如「下山赶集 我只是来买盐的」「新洞府 漏雨也算福地」。作品禁梗时，后半用老话或诗句。

## 修炼怎么写

- 日常重复修炼和跨时段积累可以用时长、法门、进展简写。突破、瓶颈、悟法、首次运用术法或神识、炼丹关键步骤和决定胜负的斗法，若承担本章转折，就展开改变局势的过程：人物如何调动灵力或神识，功法/术法/剑招如何起效，身体、法器或环境如何反馈，哪里受阻、怎样判断，以及代价如何改变下一步。细节服从本书已经确立的规则，不套用通用的灵气入体模板；不写重复运功的慢镜头。
- 首次学习或试用时，可以让误差、意外、限制或代价暴露门道，但必须来自人物能力和本书规则；不要把修炼、突破、炼丹固定写成“先出糗、后成功”的同一套节拍。
- 打斗可以短促，关键斗法要让修为机制参与胜负：灵力控制、神识判断、功法特性、境界压制或已建立的术法如何创造机会、限制选择并留下消耗。能跑就跑适用于人物判断，不把所有战斗都缩成几招兵器往来。

## 叙述口吻

- 第三人称贴着主角，叙述者像个爱吐槽的说书人：在叙述句里直接带出主角或一群人的心声和吐槽，不加引号，也不挂「他心想」，可以带叹号或问号；写一群人眼红、着急时，直接替他们把那句心里话喊出来。
- 叙述者的吐槽可以用现代口语和网络梗，一章几处，落在眼前的具体事上。主角是穿越者或带现代口吻的人物时，他自己的台词和心声也可以用；土著人物的台词说本土的俗话。
- 动作衔接口语：连忙、瞬间、竟然、不过、似乎、也是、随即、突然。「竟然」写意外，「不过」写转折，按需要用，不配额，也不要一连几句都靠它们衔接。
- 表情和动作可以夸张成漫画式，夸张本身就是笑点：脸憋得通红发紫、一个激灵、浑身一震、气得直接栽倒。「眼中带着……」「眼中闪过……」后面跟一个具体的态度或一句心里话，比如眼里明明白白写着「又是你闯的祸」。咧嘴一笑、微微皱眉、重重点头这类朴素动作照常用。
- 心理活动是主角的嘀咕、自吹和小算盘：给自己封个大名号自嗨、记仇、占点小便宜、给自己找台阶。大段心理挣扎不写。
- 写景平时很少，只在出发、离别、岁月流逝和夜深这类时刻给一两句偏古典的景（风、落叶、月光、远山），这是这套文风唯一允许抒情的地方，写完就收。
- 比方从人物的生活里取，越土越好笑；不用文艺意象。

## 段落与句子

- 短段为主，一段多在十几到五十字之间，很少超过六十字；两千字一章七八十段。一段常是一句流水句，主语、动作、结果用逗号连起来，中间夹四字词。
- 叹号放开用：对白、喊声、拟声词和叙述里的吐槽句都可以用，大惊时用「！！」「？！」；平铺的叙述照常用句号。
- 省略号常用：尴尬、无语、话说一半、试了又试没结果。旁人或搭档无言以对，写成「某某：“……”」单独一段。
- 拟声词单独成段做节拍，拖音用破折号：「轰！」「嘭—」「嗡—」；拖长的喊声、叫声用「~」。破折号别处不用。
- 同一个动作连做三次、第三次变调，可以做成一个笑点（连试三样都没反应，接连几次「异变突起」却都落空），一章至多一处。
- 场景切换用单独一行「……」，或一行地点「某某宗内。」；时间推进用一句起段：「次日，……」「半年后，……」「又是一年过去，……」。

## 对话

- 对白约占全文两成，有台词的段落四成上下。说话直白口语：咋、啥、呀、啊、呢、吧、嘿嘿、哈哈；粗口点到为止。
- 先写动作或神情，再用冒号或逗号接台词，比「台词＋某某说道」更常见。说话提示朴素：笑道、说道、大笑、低声道、叹道、惊道。
- 主角对搭档话多、称呼亲昵；对外人客气圆滑，拱手、称师兄道友，遇到不想答的就打个哈哈。
- 配角各有派头：古板的人一本正经，老江湖呵呵一笑讲道理，年轻的叽叽喳喳。一本正经的人说出拆台的话，接一段「众人：“……”」，是常用的笑点。
- 修仙常识多从闲聊里得来：主角不懂就问，对方当他是个怪人，讲完主角才发现自己以前吃了大亏，这一下就是笑点。

## 数字与金手指

- 金手指提示极少。原作一百章里系统提示只出现五次，形式固定短小；收益大多直接写进叙述（「他把这次的点数加在了速度上」），偶尔用一行「某项，几点。某项，几点。」式的短行列出当前数值，不加框线、不出面板。
- 数字以汉字为主：年数、岁数、灵石块数、炼气几层；阿拉伯数字只用于属性数值或个别梗。
- 金手指的效果写成生活里看得见的变化和笑点：力气大了干活顶两个人，跑得快了逃命有底。第一次用某样新能力，常是先出糗再摸清规律。
- 这套文风不靠算细账。作品要求核算点数、天数、价格时，照作品设定算对，一两句带过，接回日子和笑点。

## 主角气质

小人物式的乐观：怕死、会过日子、爱占点小便宜，嘴上自吹实际很怂；记仇，但报仇不急，能等；重情义，受过的恩一定还，帮过他的人他送到最后；看得开，不当救世主，旁人的大事远远看着。作品对主角性格另有设定时以作品为准，只借这套口吻。

## 审稿与修订

- 以下是本文风的正常特征，不要当作毛病修掉：夸张的表情和动作；带具体内容的「眼中……」；叹号、省略号、拖音的波浪号；单独成段的拟声词和「某某：“……”」；叙述里直接带出的吐槽和心声；时间一句跨过；送别处一句短感慨和一两句景；成语、老话的戏用。
- 真正要修的是：放进哪本书都成立的情绪套话（倒吸一口凉气、心跳加速、深吸一口气）和空洞的「眼中闪过一丝复杂」「眼中大惊」；笑点只靠堆梗、粗口而处境本身不好笑；搭档只当摆设、没有自己的反应；时间跳过去却不交代变化，或用「正想着，天色渐渐暗了下来」式的空过场；反复写同一种情绪反应，或在重要收获、危险、转折之后完全没有当事人的反应；离别以外的大段抒情；主角说教或大段心理挣扎；逐条念设定；规矩、流程由叙述者或某个人物一口气讲全，人物说话像贴出来的告示（改成只说跟他自己有关的那半句，用他平时的口气，让对方插嘴、打岔）；开头或过场把几天的日常按「先……再……待……便……」的次序工整地交代一遍（改成从其中一个时刻起笔，日常一个分句带过）；日常重复修炼被逐轮写满，或关键突破、悟法和斗法只报结果；系统提示刷屏；作品禁梗时仍出现网络梗或现代词；照搬原作的名字、道具、梗、原句或本 Skill 的示例；「不是……而是……」式对照和排比收束；一章没有任何看得见的变化。
- 修仙质感：检查灵力、神识、功法、术法、法器、阵法和境界差是否实际改变人物能感知什么、能做什么、要付什么代价。若把灵力和境界词删掉，整场仍只是普通兵器交手或体能较量，就指出修仙机制只作了装饰；不要靠堆名词补足。
- 只改文字时，保留原有事件与事实，把叙述、对白和段落改回上述口吻。
