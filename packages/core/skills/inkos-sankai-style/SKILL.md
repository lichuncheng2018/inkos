# 三开流玄幻文风

本 Skill 是中文玄幻、修仙、仙侠、修真、高武作品的可选文风（默认文风是 inkos-ziling-style，两者不同时使用），依据三开大神《修仙，每天十倍收益结算》《氪命强化，可寿元每分钟都会增加》《一证永证，提前五百年登陆修仙界》约 230 万字正文归纳。

- 用于正文写作、续写、修订、润色和文风审查。规划和设定只取其中和排事件有关的部分（招牌手法、修炼怎么写、节奏与章法），不套用语言细则，也不把本 Skill 的写法写成章纲里的措辞要求或次数配额。状态结算不受本 Skill 影响，事实照常用平实的话记。
- 优先级：用户当次的明确要求 > 作品 `story/style_guide.md` > 本 Skill > inkos-long-writing、inkos-short-writing 中的通用中文表达默认。本 Skill 没有规定的地方照通用默认执行，尤其是细节专属、不用情绪套话、不写复述句。章长以作品设置为准。
- 只学写法。不得搬用原作的人名（例如原作反复使用的主角名「叶浩」）、地名、功法名、金手指设定组合、情节顺序和原句；也不模仿原作的错别字、前后不一致和「PS」式作者注。
- 这套文风好读，靠的是账算得有意思、道理讲得明白、爽点给得及时，不是句子越简单越好。用词朴素，细节和人物的眼光要具体。

## 招牌手法

这几样最能让读者认出这套文风。用哪样看这一章的事，不凑数：规划时挑贴得上本章事件的一两样，排成具体的场次或节拍；写正文时把章纲排了的写足，章纲没排的，碰上合适的处境再顺手用。

1. 算账。每有收获、交易、突破或开销，就在叙述里算一笔具体的账：数量、单价、总数、天数都写成具体数字，再推出它对主角意味着什么，比如顶原主几年的积蓄、够吃几个月、离下一层还要几天。不写「报了个价」「换了不少灵石」「高出两成」「顶好几个月」这类虚数。账要算对：单价、数量和总数前后对得上，同一样东西的价格不改口。账从主角自己的眼光算：他在乎什么、拿什么作比较，账就落在哪里。这是叙述者和主角的口头盘算，不受 inkos-long-writing 中「不照搬账本、清单」的限制；那条针对的是表格化、报告腔的罗列。
2. 把道理讲明白。叙述者直接解释规则、价值和动机，读者可能疑惑的地方主动交代原因。讲清楚就回到眼前的事，不在后面再补一句总结。
3. 对话推进。有人在场时，对白占两到三成，说话直白，说话提示朴素。
4. 高兴就写高兴。收获时先写主角的喜悦和一句短感叹，再写他因具体顾虑收住；喜悦和顾虑都落在这一次收获的具体内容上。穿越者的现代口吻带一点小幽默。
5. 信息差。旁人震惊、误判、背后议论，读者始终比配角多知道一些。

## 叙述口吻

- 第三人称跟着主角走。叙述者直接把事情讲明白：世界规则、境界高低、物品品阶和价格、人物来历、主角为什么这样做。每次讲两三句，讲清楚就回到眼前的事，不铺成大段设定，也不把金手指规则逐条一句一段地念出来；规则在第一次用到时交代用到的那部分。
- 可用的连接词：「毕竟……」补原因，「不然的话……」点出后果，「也就是说……」把数字和规则推成结论，「只可惜……」引出限制或转折，「至于为什么……，是因为……」回答读者的疑问，「殊不知……」制造信息差。按需要用，不按次数配额；同一个连接词在一章里不要反复出现，也不要每段都挂连接词。
- 动作衔接朴素：便、连忙、顿时、旋即、随后、于是、很快、没多久。允许「也是」「便」这类口语虚词，不追求书面雅致，但不要一连几句都靠它们衔接。
- 指代以清楚为准，主角名和「他」按需要用，对话对象可以称「对方」。相邻段落不要都用「主角名＋动作」开头，可以从物件、声音、对话或结果起笔。
- 情绪可以直接点名，但要落在具体处境上：这一刻他做了什么、停了一下、注意到什么、说了句什么。不用现成的表情套话，例如眼前一亮、倒吸一口凉气、嘴角露出一丝笑意、心跳加速、深吸一口气、愣住了；不为情绪配成套的呼吸、心跳、指节细描，也不用文艺腔的比喻渲染。
- 比方少用。要用，就从人物自己的生活经验里取一个具体的东西作比，一章至多一两处，比得准、比得有趣，不用抒情意象。
- 心理活动写成人物此刻的盘算、自问和嘀咕，带他自己的口气和小算盘。主角独处时可以出声说一两句短话，其余交给叙述。
- 幽默来自具体的东西：穿越者拿现代经验对照眼前的事、对自己「开挂」的自知、金手指规则带来的意外后果。点到为止，一章至多一两处。

## 段落与句子

- 以短段为主，一段多是一句完整的流水句：主语、动作和结果用逗号连起来。交代规则、算账或写一个要紧的瞬间时，可以一段写满几句；三五个字的碎句段只在强调时用。
- 句子以中短句为主，不写长难句、倒装和排比。长短句交替，避免一连十几段同样长短、同样结构。
- 叹号克制，每千字不到一个；问号更常见（自问、互相询问）。省略号少用，破折号基本不用；大惊时偶尔用「！！！」。
- 拟声词单独成段，做一下节拍：「嘭！」「噗！」「扑通！」。
- 写景只写和眼前事有关的东西，但要写具体：挑一两样能看出这个地方、这个人处境的细节，不用放进哪本书都成立的通用描写。新物品、新法术第一次出现时，用三五行写清样子、品阶、效用和价值，之后直接叫名字。招式只在出手的那几行写得热闹，其余照常朴素。
- 场景切换用单独一行「……」，或一行简短的地点、时间：「主殿。」「三天后。」不写「正想着，天色渐渐暗了下来」式的空过场。

## 对话

- 对白直白口语，功能明确：问价、讲规矩、提醒、讨价还价、互相调侃。称呼清楚：师兄、师妹、掌柜、前辈、长老。
- 说话提示朴素即可：说道、笑着说道、点了点头、询问道、解释道，不必变着花样，也不要每句都挂同一个。常见三种排法：台词单独一段，下一段写说话人的动作；先写动作再用冒号接台词；台词之后接一两段说话者的盘算或叙述者的解释。
- 同一个人连说几句，每句各成一段。短促的命令或喊声单独成段：「收。」「去！」「再来！」
- 配角各有一套简单的算盘：贪心的想占便宜，精明的会掂量后果，老实的讲情分。反派不降智，出手前想清楚得失。说话方式跟着各自的算盘走，不靠人人说俏皮话。

## 数字与金手指面板

- 数量、价格、属性、年限多用阿拉伯数字（380斤、15块下品灵石、3200点气血、300年寿元）；小数目和固定说法用汉字（两季、三年、一阶上品）。交易写清单价和总价，收成写清多少株、多少斤。
- 收益要能比较：和凡人、同门、过去的自己比，换算成「相当于苦修多少天」「要不吃不喝干多少年」。
- 系统、天赋提示用【】，一条一行，句子短而固定，例如【恭喜你领悟技能：某某】【消耗某某，某某已小成！】。属性面板写成「境界：某某」「气血：某某」这样的冒号行，不加框线。提示只在获得、结算、突破时出现，全书平均每千字不到半条。没有系统的作品照样算账，只是不出面板。
- 提示之后立刻接主角的反应和换算：先说多了什么，再按每分钟、每小时、每天推算，算出离下一个境界或目标还要多久，最后落到这对眼下意味着什么。

## 一笔账的写法

先写一个具体的数字事实（价格、产出、扣罚、增长），再换算成对主角的意义（顶几个月月钱、离下一层还要几天），接主角这一刻的反应，然后回到眼前的事。反应落在这笔账的具体内容上，不用通用的感叹和表情，也不在后面补一句总结。

## 修炼怎么写

- 修炼写成看得见的进展：用的什么法门，练了多久（一炷香、三个时辰、一整夜），到了哪一步（第几层、熟练到什么程度、丹田攒了多少），离下一步还差多少天，和同批的人比快了还是慢了。
- 打坐本身两三句交代：坐下、用了什么法门、坐了多久、外面有什么动静、起身时什么样子。不要慢镜头写灵气怎样入体、沿经脉流转、归入丹田，也不要用「气感清楚」「稳稳接住」「有了把握」「心里满是欢喜」这类体内感受连写一整段。
- 篇幅给修炼的结果：进展换算成一笔账，法门用进差事或斗法后有什么不同，旁人看见了怎么想，主角接下来打算怎么练。

## 节奏与章法

- 一章围绕一件具体的事推进：一次收获、一笔买卖、一门技能升级、一次突破、一场短战或一次要紧的谈话。每章至少落下一个看得见的进展：数字变了、东西到手、境界提升或关系变化。规划时把这件事拆成当场发生的步骤（谁在场、在干什么、数字是多少），不要停在「激活金手指」「验证系统」这种功能标签。
- 这件事通常是修炼这条线上的一步：练功、学法、练术、服丹、突破、斗法、得机缘，或把所学用进差事和买卖，写清练了多久、到了哪一步、离下一步还差多少、用在哪里、旁人怎么看。卷纲给的是差事章时，从差事里找出这一章的进展：法门怎么用进差事，差事做完怎么修炼，修炼有什么进展。
- 章纲里的每条事件都为这件事服务：推进它、阻碍它，或写出它的结果和代价。这件事发生在一个已经在转的地方，旁人各有打算，不是来给主角当道具的；但写进章纲的旁人事务要和这件事有关：抢他的时间、和他比进度、给他使绊子，或看见他的变化。和这件事无关的闲事不写进章纲。
- 金手指的提示和选择用一两条事件交代。完整规则和以后的推算不单独占事件，用到哪条写哪条。
- 爽感来自持续积累和被低估：主角藏拙、算账、稳步变强；旁人震惊、误判或背后议论，读者始终比旁人多知道一些。不是每章都要打脸。
- 冲突短而干脆：对手的动机一两段写清，主角出手利落，结束后清点战利品，再用一两段讲明为什么能赢（熟练度、底牌、境界差）。
- 大收获之后给一段过日子的戏：吃一顿好的、睡一觉、逗灵宠、和朋友闲聊，然后顺势定下一步计划。
- 主角离场后，可以切到配角那边写一小段：他们怎么议论、怎么误会、各自打什么主意。
- 章与章像连载一样首尾相接，下一章直接从上一章最后的瞬间写起。章末停在自然的悬停点：一句发问、有人上门、一个反应、一个即将揭晓的结果。原作约三分之二的章停在叙述句上，三分之一停在一句对白上，停在系统提示上的极少；不用「更大的机缘在等着他」「他的修仙之路才刚刚开始」之类的套话。
- 章名短而直白，点出本章的收获、转折或一句台词，常带数字，也可用逗号连接两件事，如「第一炉丹」「炸炉，入门」「一株三百年」「你也配」。

## 主角气质

穿越者式的现代口吻：精明务实，谨慎低调，懂享受。对强者客客气气，对要他命的人下手不犹豫，事后很快放下。重情义，有好处会分给自己人。

## 审稿与修订

- 以下是本文风的正常特征，不要当作毛病修掉：朴素口语；叙述者直接解释规则、价格和动机；对白里交代价格和规矩；阿拉伯数字和具体的账；短段；朴素重复的说话提示。
- 真正要修的是：现成的表情和情绪套话；放进哪本书都成立的通用描写；描写或算账之后替读者下结论的复述句；逐条念设定的段落；“不是……而是……”式对照、排比收束和一句话结论段；连续多段同一主语加动作开头；空过场；照搬章纲、参考文本或示例中的现成句子；文艺腔、比喻堆砌、景物抒情和哲理金句；该算账的地方用虚数糊过去；冷冰冰的复盘报告和清单式盘点；大段心理挣扎；一章没有任何看得见的进展；为了显得紧张硬塞的悬念和打脸。
- 只改文字时，保留原有事件与事实，把叙述、对白和段落改回上述口吻。
