# 大白话表达带点幽默的中文文风

这是非玄幻小说的正文默认，不是情节模板。未标题材但创作方向明确是玄幻、修仙、仙侠、修真或高武的作品，不用这套写法。用户当次的明确要求、作品自己的作者意图和文风约定优先。以下写法优先于通用正文建议；没提到的照常执行。改文风时保留原有事件、事实和人物动机。

用大白话把事说清楚。一句够了，就别换个说法再讲一遍。人物想自己开公司、想让中国的大模型领先，就按他当时会想的话写；没把握时问自己一句也行。不另编一段往事替他找理由，也不把刚冒出来的念头写成正式宣言。

把要紧的话先说，补充的话顺着说。人物说话和心里话可以带“就是”“然后”“但是”，合口气就留。

先分段，再接逗号。按手机阅读的节奏写，一段讲清一个动作、一个反应或一层意思，平常尽量控制在60字以内。普通正文每段最多80字，含标点，不计空白。话头换了就另起一段，段与段之间空一行。比如说完终验和尾款，转到为什么厂里还得留人，就另起一段。写章和改章交稿前，逐段检查这次写过的正文，超过80字的都在意思说完的地方拆开，再检查一遍段长。

末尾还没有收尾符号时，一段陈述正文只在段末放一个句号。段内还在讲同一个意思，就用逗号接下去。话头已经转了，就用句号收住，空一行再写，尤其是从眼前转到回忆，或换了时间和地方。段尾已经是引号、问号、感叹号或省略号，就在那里收尾。交稿前逐段同时检查句号和段长，逗号接起来超过80字就按意思分段。必须逐字保留的系统提示或引文另起一段，原样引用。

> 一项就一项，他桌上正好有一项，前前后后改了几轮还没做完。

> 下一张正好反过来，实物没伤，程序却给剔了。
>
> 下午在工位上，师傅拿的就是这一件，遮光板翘起的一角刚用黑胶带压住，他把零件往灯底下一送，叫张椿承看屏幕。

写对话时，想一下人物在跟谁说话、这一句想让对方听明白什么。问星穹“也是你吗？”，带一点试探，跟同事说“我在现场呢”，是想让他放心，真怕他顺手帮忙，就嘱咐一句“你在旁边看，千万别替他点”。语气从两个人的关系和眼前的事里来，一个“吗”“呢”或“千万”用得合口气，就能让人听出说话的人在意什么。

普通交代直接转述。报个时间、转发消息、确认安排，写进叙述一句带过。人物表态、做决定，或这句话的口气本身有分量时，再用双引号留原话。电话和聊天接了几轮，照样挑出需要读者亲耳听见的话，其余顺手转述。

留下的台词用半角直双引号 `"`，夹在叙述里就写成 `叙述"台词"叙述`，开引号直接贴着前面的字，省掉用来引出台词的冒号。同一个人连着说的话只用一对引号，把“他说”或比划一下之类的小动作放在整句前后。台词和心里话也照这个节奏，一对引号里的分句用逗号往下接，陈述台词说完就收引号，段尾到引号就结束。后面还有叙述，直接接着写。

> 木子在屏幕上打了个时间，十七分钟。
>
> 张椿承低头看了眼刚过五万的余额"不卖，源码不出，软件也不买断"

都市故事里，设定可以离奇，人的反应照真人写。先问这个人碰上这事，第一反应会做什么、想什么。下一步从他刚看到、听到或想到的事里来。该吃惊就吃惊，缓过劲来先想怎么花也正常，不必每一步都冷静有条理。别为了替作者交代设定，让人物去做他当下没理由做的检查。

- 从事情发生的地方写起。手机先震，人醒了才去摸。一个细节写出来，最好能让人物认出什么、显出他是什么人，或在后文用得上。三样都不占的细节，删。剪歪的贴膜扎手，能让人认出早已换掉的手机；再回忆店员怎么取卡就重复了。不为显得有文笔，先摆一圈屋里的陈设、光线和身体反应。
- 镜头跟着视角人物此刻的感官和注意力。人还盯着余额，就先写他怎么接住这笔钱，别急着交代他还没留意的屋子。等他把目光从手机上挪开，认出这是28岁时在深圳合租的房子，再写桌腿下还垫着那张外卖菜单。细节到人物注意到它的时候再写，不用每句都加“他看见”。
- 章纲不是按顺序念的清单。挑这一场最值得读者亲历的那一下，把当时的动作、念头和反应写足。相邻的过渡动作能合就合，例行的走路、等人、换页面可以一句带过。不平均分配篇幅，不让每条事件各占一段。同一件事也分轻重：从短信切到手机银行一句就够，发现金额不对劲、数完还不敢信，才值得停下来写。
- 结果一句能说清就直说。需要让读者陪人物经历这一刻时，再写他当下怎么理解、哪里不敢信、真会做什么。只有“又数了一遍”还是在报动作，要紧的是他为什么又数、数完怎么接住这件事。情绪直接写，“他有点看傻了”就够了，不必凑呼吸手指喉咙，也别再用比喻或小动作替读者确认一遍——“好像那一万亿会从摄像头里漏出来”就是叙述者替人物抖机灵，不是人物自己想歪。人物嘴欠（“查个屁”“负责录像”）留，叙述者找补删。已经信了还要逐项核验，就是在写对账。关键一句可以单独成段；不要把“先怀疑再确认”套给每场戏。

  反例：他把金额抄下来，四位一组，核对电子回单后确认金额为一万亿元。

  正例（看口气和反应，不照抄去写别的场面）：

  > 个、十、百、千、万……
  >
  > 数到亿，左边怎么还有四位？
  >
  > 准是哪儿数岔了，他又从个位数起，这回数慢了点，数到亿，左边还是四位。
  >
  > 张椿承有点看傻了。
  >
  > 一万亿。

- 心里话要像这人真会想的，允许嘴欠、自嘲、想歪一点。笑点可以很轻：突然暴富，想到怎么挥霍，点两个嫩模，连谁负责录像都分工好了；发散一句，转头还是想起自己干的那行。这类有点荤、有点荒唐的想法合人物就留，不用替他找补、解释笑点或借题说教，也不必扩成一段戏。
- 大众成语用得贴切就用，几个字能说清，不再补一段解释。“遥遥领先”可以直接表示领先很多，也可以是人物顺嘴用的现实梗。用梗要合人物、时代和处境，不为幽默硬插一句。
- 现代背景里，正文交代具体年月、时间或年龄，默认写“2016年1月”“8点”“28岁”。屏幕和票据上的数字按所见格式写，重写时别无故把已有的阿拉伯数字换成汉字。人物说话和心里话按口语来，“个、十、百、千、万”“一万亿”照写，不强行换成数字。

- 审改先看一整场戏的轻重和口气：是不是过渡写得很细、真到要紧处却只报一个结果？哪处细节帮助人物认出、判断或行动，哪处只是把同一个意思再说一遍？一句心里话就能说清的，不扩成一段动机说明或宣言。把多余的过渡并掉，把笔墨留给人物接住事情的那一下。别靠多加一段感想解决，也不要求每句都推进剧情。合人物、合处境的直白情绪、玩笑和现实梗不是瑕疵；查的是梗从谁嘴里出来、是否出戏，不是见梗就删或把玩笑磨成公文。

## 可选打磨

- 小动作、分工和风险挤在同一句里，读着费劲时，可以把分工和风险分开说。有人当场接下责任时，“我接”这样的话可以单独成段，让读者听见那一下。
- 新写的系统反馈可以先报结果，有下一步就接一句，涉及权限就直接问。留住观察能确定的范围，比如“未见明显划痕”。已经约定要逐字引用的提示照原样写。
- 一场戏要等检测或复测结果时，可以先让读者知道怎样才算过。人物挑资料、留样或安排测试时顺嘴交代一句，接下来看到结果，读者就知道它过线没有。
